# 新 UI 接口清单

## 首页必填入口

1. 出发地：城市选择器，当前仅中国大陆城市。
2. 目的地：城市选择器，当前仅中国大陆城市。
3. 去程时间：最早可出发时间、最晚可出发时间。
4. 是否往返：默认开启。
5. 返程时间：最早可返程时间、最晚必须抵达时间。
6. 交通方式：火车、飞机，可多选。
7. 推荐偏好：最省钱、最均衡、最快到达。

## 建议保留的学生约束入口

- 总预算。
- 返校或宿舍门禁截止时间。
- 最大中转次数，MVP 默认 1 次。
- 可接受的最短换乘时间。
- 是否接受跨夜和住宿。
- 行李情况，后续用于计算机票附加费。
- 是否接受异站换乘，后续用于计算市内交通成本。

## 结果页必须展示

- 去程与返程的完整时间线。
- 总票价、住宿费、市内换乘费和总成本。
- 总耗时、交通方式、车次或航班号、站点。
- 风险提示：跨夜、凌晨到达、门禁超时、换乘过紧。
- 三个主方案标签：最省钱、最稳妥、最快。
- 数据来源与查询时间；价格只作参考。

## 当前不应出现的入口

- 国际节点开关。
- 国家或国际机场选择。
- 三段跨洲路线。
- MCP 服务启动、API 地址、模型名等开发者设置。
- 旧版日志窗口、全量数据导出和枢纽数量档位。
