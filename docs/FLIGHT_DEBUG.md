# 航班查询调试记录

日期：2026-09-27。修复不改变网站视觉与布局，不加入演示机票或未经验证的第二数据源。

## 开源参考

- [Go-Home](https://github.com/huanchong-99/Go-Home)：README 说明机票串行查询；项目现有 FlightTicketMCP 也是这套实现的衍生代码。上游仍包含前 10 条截断、捕获异常后返回空列表等逻辑，因此未用上游文件直接覆盖本地修复。
- [DrissionPage 的 ChromiumOptions 实现](https://github.com/g1879/DrissionPage/blob/master/DrissionPage/_configs/chromium_options.py)：使用其原有 `set_local_port`、`set_user_data_path` 和超时配置 API。`auto_port()` 会替换持久化 profile，因此本项目分配独立调试端口并保留 Cookie 目录。

## 修复边界

1. Provider 串行调用；MCP 工具再对整个浏览器生命周期加锁。macOS/Linux 上用文件锁保护跨进程共享的 Cookie 目录。结束和验证码重启操作都在锁内，不复用默认 9222 端口，也不关闭用户自己的浏览器。
2. 页面状态根据可见元素、渲染文字与 WhaleGuard 标识识别，不再扫描脚本中的泛化 `login/verify` 字符串。点选图标、拼图滑块、登录弹窗优先于底层“未找到航班”提示；仅明确且未被验证遮挡的无航班状态可成功返回空列表。加载不完整、浏览器断连和解析失败均返回错误。
3. 验证等待使用单调时钟的 120 秒截止时间，而非 120 次轮询；1 条航班也可通过验证完成判定。搜索总预算 240 秒，MCP 300 秒。只允许启动失败重试；超时或工具错误不重发。若超时任务仍未回复，MCP 客户端保留它并阻止新搜索，直到真正结束。
4. 解析所有已加载航班，再由 Provider 筛选出发时间。不再只取前 10 条。仍只把直达航班作为单个行程段，不将中转航班错误合并成直达。
   数据项缺少有效时间或价格时报告响应异常，不再静默变成无票；价格中的千位分隔符与小数也不会被截断。
5. 网站为每次规划生成 `query_id`。`POST /cancel` 支持活动查询和先取消后开始的竞态；取消信号传到专用 `cancelFlightSearch` 工具，轮询/解析检查信号，之后执行浏览器清理。等待锁的查询也可以取消。取消仅作用于指定请求；当前不可中断的浏览器短操作结束后才释放资源。

## 错误码

| 错误码 | 含义 |
| --- | --- |
| `SOURCE_BLOCKED` | 携程 WhaleGuard 拦截 |
| `VERIFICATION_REQUIRED` / `VERIFICATION_TIMEOUT` | 验证或登录未完成 |
| `CONTENT_NOT_READY` | 页面未加载完或结构变化 |
| `PARSE_FAILED` / `PAGE_DISCONNECTED` | 解析或浏览器连接失败 |
| `SEARCH_TIMEOUT` / `SEARCH_BUSY` | 超时或其他服务仍占用浏览器 |
| `QUERY_CANCELLED` | 指定任务已取消 |

只查航班且数据源错误时 `/plan` 返回 503；混合交通查询保留真实可用的火车结果并附 `source_errors`。已取消的 `/plan` 返回 499。

## 2026-10-03：Safari 后台标签与验证码误判修复

检查时本地 8765、8766 均未监听；按原启动脚本恢复 8766 的 `live_all` / `safari` 服务。未增加后台守护或开机自启动，本地服务仍需保持运行。

修复前，北京—上海 10 月 7 日查询在专用标签未选中时等待约 90 秒，返回 HTTP 503 / `CONTENT_NOT_READY`。同一 URL 的 Safari 原生文字仅含日期、筛选栏，没有航班列表；选择该标签后立即取得 KN5977、HO1254、MU8201、CA8341 四条可解析航班。10 月 6 日在已选中专用标签时约 8 秒成功，确认后台页面渲染是可重复的失败条件，而不是该线路确实无票或此次登录失效。

修复内容：

- 查询脚本同时记录专用标签及其所属窗口，准备查询时自动选中该窗口的标签。复用标签时先选择再导航；不强制激活 Safari 应用，不启用 JavaScript 自动化或导出 Cookie。
- Safari 检测补齐点选图标、拼图、滑动/人机验证及英文 CAPTCHA 等文案。验证层优先于底层无航班状态和旧航班列表；仅人工验证解除后才接受数据。到达等待期限且最新页面仍有验证时返回 `VERIFICATION_REQUIRED`，验证已解除但列表未加载时返回 `CONTENT_NOT_READY`；取消仍返回 `QUERY_CANCELLED`。
- 新增 6 项 Safari 回归测试，覆盖 10 类验证文案、空列表/旧列表遮挡、解除/再次出现验证和取消。Python 全量 62 项、前端 22 项测试均通过；修改后的 AppleScript 在 macOS 正常应用词典环境编译通过。
