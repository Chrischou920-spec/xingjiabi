# UI 优化与验收记录

日期：2026-10-01。范围：`web/index.html`、`web/styles.css`、`web/app.js`。票务 Provider、MCP、端口与请求结构未在本次 UI 改造中更改。

## 评审参照

品质参照 Awwwards、Webby Awards、FWA，不代表获得这些奖项或官方认证。参考 [Webby 官方评审标准](https://www.webbyawards.com/judging-criteria/) 中对结构、视觉、功能、交互、创新与整体体验的要求，优先保证工具的可用性与一致性。

## 迭代

1. 去除多层圆角面板与竖向双入口栏，改为轻量顶部导航、单一条件表单和联动票券摘要。
2. 将常用条件放在首层，住宿、门禁和完整航班渐进展开；增加方案价差、耗时差。
3. 浏览器发现桌面表单偏长、城市箭头放大，已修正控件比例和横向条件排布。
4. 320px 验收发现长城市名与交通标签换行不佳，已调整长名字号、图标与小屏排布。
5. 200% 文字验收发现时刻控件被挤压，已用字体相对容器查询重排，1024px 与 375px 复查日期、时刻和价格完整可读。
6. 去除会干扰离屏内容呈现的详情入场动画，保留按下、选中、箭头状态和可中断页面切换。摘要与其他焦点的 DOM 顺序与视觉顺序一致。
7. 最终横屏及大字复查，修正 320px 折叠摘要过高、200% 字体结果标题受按钮挤压的问题。

## 八项自检

| 项目 | 验收要点与处理 |
| --- | --- |
| 排版 | 中文系统字体、分级字号、价格与时刻采用等宽数字；修正长城市名。 |
| 留白 | 同组紧凑、跨组分隔；桌面条件并排，移动端单列；不添加空白宣传区。 |
| 视觉层级 | 航线、日期、查询按钮和推荐成本优先；次要条件、来源明细渐进展开。 |
| 色彩 | 语义令牌统一管理；文字和操作色实测对比度，错误不只靠颜色表达。 |
| 动效 | 100 / 180 / 320ms 节奏，transform / opacity 为主；无滚动劫持或移动背景。 |
| 微交互 | 交换、开关、多选、偏好、摘要联动、查询锁定、等待时间、取消与焦点恢复。 |
| 响应式 | 320 / 375 / 768 / 1024 / 1440px、横屏与 200% 字体；检查无水平溢出。 |
| 原创性 | 航线票券与时刻表视觉语言服务本产品；没有复制奖项网站的宣传页或无关模板。 |

## 已验证

- Python 后端测试：56 项通过。
- UI 合约、请求、状态、来源降级、转义、对比度、可中断微交互与减弱动态效果分支测试：22 项通过。
- 浏览器：演示往返搜索返回 3 个方案；飞机单独搜索返回 1 个方案；完整航班展开显示 2 班；单程禁用返程和门禁；城市交换和多项错误摘要定位正常。
- 慢查询验收：4 秒延迟演示服务，取消后字段恢复、保留条件并显示取消状态；再次查询仍可返回结果。
- 普通 375px 控件几何检查：可用主控件均不小于 44 × 44px；没有水平溢出。
- 200% 字体：375px 与 1024px 日期/时间重排；375px 结果页时刻框没有内容裁切。
- 最终逐断点读取实际视口：320 / 375 / 768 / 1024 / 1440px 与 812 × 375 横屏；规划与结果页均无水平溢出。
- 浏览器已验收页面无 JavaScript error / warn。
- 真实回归：上海 → 北京，2026-10-08 单程，00:00–23:59，火车 + 飞机。12306 返回 3 个方案（G44、G12 二等座 / 无座）；Safari 航班来源返回 CONTENT_NOT_READY。本轮确认真实火车展示及来源失败的降级提示正常，不把本次回归描述为机票成功。

关键对比度：次要文字/画布 4.85:1；次要文字/输入底色 5.14:1；按钮白字/钴蓝 5.57:1；摘要次要文字/墨蓝 9.20:1；错误文字/错误底色 5.74:1；输入边界/输入底色 3.23:1。

## 交互增强（2026-10-01）

- 修正摘要中与统一图标不一致的飞机路径，改为复用飞机图标、朝向目的地，并避免机翼与航线穿插。
- 导航和推荐偏好使用共享选中滑块，连续切换从当前显示位置重定向；布局变化即时重算，不动画宽高。
- 按钮支持指针与键盘波纹、按下缩放、悬停抬升及箭头前移；选项支持图标反馈与勾选线条绘制。
- 城市交换、已确认条件和摘要值采用轻量位移 / 淡入；输入过程中不逐字跳动。详情保留原生键盘行为，使用始终可见的短幅淡入。
- 仅选火车时摘要交通图案同步变化；仅查询等待期间有虚线流动，取消和完成后停止。
- 自动化补充快速切换、图标方向、选中滑块最终位置、波纹清理及减弱动态效果；语义状态先更新，正确性不依赖动画完成事件。
- 浏览器复查：快速切换偏好与页面后滑块正确对齐；波纹完成后没有遗留节点；4 秒演示查询支持键盘提交、取消、重新搜索返回 3 个方案。375px 触控检查、812 × 375 横屏和 375 / 1024px 的 200% 字体均无水平溢出；浏览器无 JavaScript error / warn。
