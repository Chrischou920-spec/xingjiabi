# 第一版 Demo · v0.1.0-demo

归档日期：2026-09-21。

## 本版本内容

- 国内单程和往返行程规划、预算过滤、偏好排序及风险提示。
- 统一火车和国内航班 Provider、MCP 调用与本地 HTTP 接口。
- 离线演示数据和 15 项自动化测试。
- UI 输入字段文档、三版页面概念设计及 Logo 设计素材。

## 验收记录与限制

- 2026-09-21：15 项自动化测试全部通过。
- 真实 12306 查询此前验证通过；这次归档未重新查询实时余票。
- 航班 MCP 通信、浏览器启动和拦截报错此前验证通过；真实航班结果仍受当前网络下 WhaleGuard 拦截影响。
- UI 目前为设计稿，交互网站、缓存降级及部分数据源失败恢复尚待实现。
- 不包含虚拟环境、依赖安装目录、浏览器缓存和构建产物；安装步骤见根目录 README。

## 启动

```bash
python3 -m student_trip.server
```

默认使用演示数据，本地服务地址为 `http://127.0.0.1:8765`。
