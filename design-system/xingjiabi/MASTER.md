# 行价比 UI 设计规范

本规范由 UI/UX Pro Max 的工具型界面检索与 Apple-design 的交互原则共同指导，适用于现有本地 HTML / CSS / JavaScript 前端。

## 产品与方向

面向国内火车、飞机及往返行程比较。搜索条件、真实票务、成本与时刻是核心内容，不新增宣传标语、虚假功能入口或购票按钮。

视觉方向为「轻量行程工作台」：浅蓝灰画布、白色表单、墨蓝票券摘要、钴蓝操作按钮。以航线、票券分隔线、时刻表建立产品辨识度；保留原有“行价比”文字标识，不重绘未经确认的图形 Logo。

UIpromax 首轮输出偏向宣传叙事，未采用；收窄为 booking / search / utility / dashboard 后，采用 Minimalism & Swiss Style 的网格、留白与字级建议。输出中的漏斗宣传结构、英文网页字体与橙色 CTA 不适配当前中文工具，未照搬。

## 基础令牌

- 字体：系统字体栈，中文优先苹方；不加载外部字体。
- 字级：辅助 0.75rem；标签 0.875rem；输入 1–1.125rem；标题 2–3rem；价格 1.875–2.5rem。数字使用等宽数字特性。
- 色彩：画布 `#edf2f6`；内容 `#172738`；次要文字 `#5b6b7c`；操作 `#235de5`；深操作 `#1746b5`；摘要 `#142c42`；摘要次要文字 `#c3d1df`。
- 控件边界 `#7c8ca0` 与一般分隔线 `#dce3eb` 分开管理。错误与警告使用语义色，并保留文字描述。
- 间距以 4px 为基础，使用 8 / 12 / 16 / 20 / 24 / 28 / 32 / 48 的节奏。
- 容器圆角 24px，控件 10–16px，胶囊只用于导航和状态。阴影只承担浅层空间区分。

## 布局与信息

规划页按「城市与路线 → 日期 → 交通与偏好 → 预算 → 更多条件」组织。门禁、住宿渐进展开；保留每个字段与后端字段映射。摘要随输入更新，手机默认折叠。

结果页按「当前查询 → 所获方案统计 → 优先推荐 → 备选比较 → 完整航班列表」组织。统计仅针对本次返回方案，不暗示全网最低。备选显示与推荐的真实价差、耗时差。完整航班列表默认折叠，数据不丢弃。

无结果、票务来源异常、演示数据和查询取消均有清晰反馈。演示与实时来源必须明确区分。

## 交互与动效

按下反馈 100ms，选择与状态反馈 180ms，页面切换 320ms；使用 transform / opacity，页面动画可中断。原生日期、时间、details 和 checkbox 保留键盘行为。无滚动劫持、自动轮播、指针跟随或持续移动背景。

交互增强：导航与偏好采用 340ms 可重新定向的共享滑块，摘要更新 240ms、选项图标 260ms、按键波纹 440ms。指针按下和键盘按键均触发反馈，不等待提交后才响应；高亮、字段值与选择状态即时落定。重复点击取消旧动画并从当前呈现位置继续。悬停仅提供轻微抬升、箭头前移与一次光泽划过，不承载核心功能。

摘要航线复用按钮中的飞机 SVG，机头朝目的地；仅选火车时换为火车图标。装饰图不使用票务进度，也不持续飞行；查询期间仅虚线流动表示等待，结束或取消后停止。原生详情展开使用短幅淡入，起始内容保持可见，不依赖动画完成事件恢复交互。

尊重 prefers-reduced-motion、prefers-reduced-transparency、prefers-contrast、forced-colors。减弱动态效果时关闭页面位移和旋转反馈；查询仍保留文字状态。

## 响应式与可访问性

覆盖 320 / 375 / 768 / 1024 / 1440px 与横屏。rem 字级和字体相对容器查询支持 200% 文字放大，必要时将日期、时刻和结果重排为单列。

主要控制区至少 44 × 44 CSS px。显式标签、跳转链接、可见焦点、页面切换焦点管理、多项错误摘要和字段内错误缺一不可。装饰图标从可访问性树隐藏。

当前为专门设计的浅色主题，不以未验证的自动反色冒充暗色支持。
